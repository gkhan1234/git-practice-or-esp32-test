What is this simulator?

This is an interactive teaching tool that shows how the ESP32 microcontroller reads an analogue voltage using its built-in Analogue-to-Digital Converter (ADC). The ADC is one of the most important peripherals on any microcontroller — it is what allows a digital chip to sense real-world signals like temperature, light, sound, and pressure.


The simulator models the ADC1 Channel 6 peripheral on GPIO34 of a real ESP32-D0WD-V3 chip running MicroPython v1.28.0. Every number, formula, and visualisation in this page matches exactly what the real hardware produces — including its imperfections.


When connected to a real ESP32 via USB (Chrome or Edge only), the simulator switches from simulation mode into live mode, reading actual voltage values from GPIO34 every 200 ms and displaying them in real time.

Purpose & teaching goals

This simulator exists to make abstract digital concepts visible and tangible. Students often struggle to understand why a sensor returns a number like 2731 instead of a voltage — this tool closes that gap by showing the full conversion chain in one place.


Specific goals:

  • Explain what analogue-to-digital conversion physically means
  • Show why the ADC produces integers, not floating-point volts
  • Demonstrate how attenuation affects measurement range and precision
  • Make quantisation error visible and measurable
  • Expose the real-world non-linearity and noise of the ESP32 ADC
  • Bridge the gap between the simulation and actual MicroPython code

How to use this simulator

1

Drag the voltage slider on the left up and down. Watch the ADC raw value, bar meter, waveform, and all calculations update instantly. This represents an analogue sensor varying its output voltage.

2

Change the attenuation setting. Switch between 0 dB, 2.5 dB, 6 dB, and 11 dB and observe how the input range and LSB step size change. Notice that finer range = better precision.

3

Enable ADC noise using the toggle. Watch the waveform become jittery and the raw value fluctuate. This is realistic — the real ESP32 ADC has ±2–4 LSB noise at all times.

4

Drag the slider near 0 V or near Vmax and watch the orange non-linearity warning banner appear. This is a known hardware limitation of the ESP32 ADC.

5

Read the Calculations Breakdown at the bottom. Every formula is shown symbolically, then with your current numbers substituted in, so you can follow the maths step by step.

6

Connect to a real ESP32 (Chrome/Edge only) using the Connect button. Apply a real voltage to GPIO34 (e.g. from a potentiometer connected between 3.3V and GND) and watch the simulator display live hardware readings.

Key concepts explained

  • ADC (Analogue-to-Digital Converter): A circuit that samples a continuous voltage and maps it to a discrete integer. The ESP32 uses a 12-bit successive-approximation ADC (SAR ADC).
  • Resolution: 12-bit means 212 = 4096 possible values (0–4095). More bits = finer steps = less error.
  • LSB (Least Significant Bit): The voltage represented by one count. At 11 dB: 3.3V ÷ 4095 = 0.806 mV per step.
  • Attenuation: An internal voltage divider that scales the input range. Higher dB = wider range, but coarser LSB.
  • Quantisation error: The rounding error from mapping a continuous voltage to the nearest integer. Maximum = ½ LSB.
  • Non-linearity: The ESP32 ADC is inaccurate near 0 V and near Vmax. Avoid these regions for precision measurements.
  • ENOB (Effective Number of Bits): Due to noise and distortion the ESP32 achieves ~9.5 ENOB — equivalent to only ~724 usable steps despite the 4096-step range.
  • Oversampling: Taking multiple readings and averaging them improves effective resolution. This is a common technique in real firmware.

Real-world applications

The ADC is used whenever an ESP32 project needs to read an analogue sensor:

  • Potentiometer — read rotary position (0–3.3V → 0–4095)
  • Temperature sensor — e.g. NTC thermistor outputs a varying voltage
  • Light sensor — LDR in a voltage divider varies with brightness
  • Microphone — audio signal centred around 1.65V (mid-supply)
  • Battery monitor — measure cell voltage via a resistor divider
  • Soil moisture — capacitive sensor outputs 0–3V analogue signal
  • Joystick — each axis is a potentiometer on an ADC pin

In all cases the MicroPython pattern is identical: read raw → scale to volts → map to physical unit.
