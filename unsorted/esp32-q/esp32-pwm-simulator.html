Calculations Breakdown

Every value shown in the simulator is derived from three inputs: Frequency (f), Duty Cycle (D%), and the ESP32's supply voltage Vcc = 3.3 V. The formulas below update live as you move the sliders.

Period T
T = 1 / f
= 1 / 1000
= 1.000 ms
One full cycle: the time from one rising edge to the next. Inverse of frequency.
Pulse width HIGH ton
ton = T × (D / 100)
= 1.000 ms × (50 / 100)
= 500.0 µs
How long GPIO16 is HIGH (3.3 V) in each cycle.
Pulse width LOW toff
toff = T − ton
= 1.000 ms − 500.0 µs
= 500.0 µs
How long GPIO16 is LOW (0 V) in each cycle.
Average voltage Vavg
Vavg = Vcc × (D / 100)
= 3.3 V × (50 / 100)
= 1.650 V
The DC equivalent seen by a low-pass load (e.g. motor, LED driver). This is what a multimeter reads in DC mode.
RMS voltage Vrms
Vrms = Vcc × √(D / 100)
= 3.3 × √(50 / 100)
= 2.333 V
Root-mean-square voltage. Represents the heating power delivered to a resistive load.
Duty → 10-bit register duty
duty = round(D / 100 × 1023)
= round(50 / 100 × 1023)
= 512
MicroPython's PWM.duty() takes a 10-bit integer (0–1023). Convert your percentage to this value before calling the API.
Phase → time delay tφ
tφ = T × (φ / 360)
= 1.000 ms × (0 / 360)
= 0.0 µs
The visual phase offset expressed as an actual time delay. Useful when synchronising two PWM channels.
Perceived LED brightness B
B = (D / 100) 1/2.2 × 100%
= (50 / 100)0.4545 × 100
= 72.97%
The human eye responds non-linearly. A 50% duty cycle looks ~73% bright, not 50%. The exponent 1/2.2 is the inverse gamma correction (γ = 2.2).
